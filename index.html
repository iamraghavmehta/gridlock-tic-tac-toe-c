Matrix Win Evaluation

The C core uses 2D array coordinates board[row][col] to evaluate 8 victory vectors in O(1) time:

// Horizontal scan
for (int r = 0; r < 3; r++)
  if (board[r][0] == board[r][1] && 
      board[r][1] == board[r][2]) return board[r][0];

// Main & Anti Diagonals
if (board[0][0] == board[1][1] && 
    board[1][1] == board[2][2]) return board[0][0];
if (board[0][2] == board[1][1] && 
    board[1][1] == board[2][0]) return board[0][2];
